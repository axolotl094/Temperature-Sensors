Temperature Sensors Lab Report

Calibration of three temperature sensors using a Pt-100 as the reference thermometer:

Pt-100 resistance thermometer (calibrated at LN₂, ice, room temperature and boiling water)
Semiconductor diode (1N4148): forward voltage vs. temperature, used to estimate the band gap
Chromel–Alumel thermocouple: thermo-emf vs. temperature
Results
Sensor	Calibration
Pt-100	R = (99.25 ± 0.85) + (0.4010 ± 0.0077)·T [Ω, °C]
Diode	V = (1.1559 ± 0.0070) − (1.433 ± 0.035)×10⁻³·T [V, K] → E_g ≈ 1.16 eV
Thermocouple	ε = (1.419 ± 0.142) − (0.0297 ± 0.0013)·T [mV, °C]
